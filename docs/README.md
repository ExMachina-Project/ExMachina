# 开发与设计文档

`docs/` 仅存放长期维护、用于项目开发的指导文档和设计文档。

| 文档 | 用途 |
|---|---|
| [开发规范](开发规范.md) | 分支、提交、评审、文档边界与发版纪律 |
| [开发环境与安装](安装指南.md) | 源码构建、隔离开发栈和验证入口 |
| [架构与设计](架构与设计.md) | 分层、运行机制和设计取舍 |
| [协议与契约](协议与契约.md) | 数据结构、API 与跨组件边界 |
| [安全模型](安全模型.md) | 执行身份、审批与防护边界 |
| [插件开发指南](插件开发指南.md) | 插件协议、扩展方式和治理约束 |
| [元智能体](元智能体.md) | 元智能体职责与演进机制 |
| [客户端兼容身份](客户端兼容身份.md) | 提供商请求身份的兼容设计 |
| [智能体模型分配](智能体模型分配.md) | 模型路由、配置和管理接口 |

审计报告、截图、验收记录、执行日志及临时任务材料不得放入此目录或提交到 Git。验证产物保存在仓库外；品牌资源位于 `assets/branding/`。文档门禁由 `.gitignore`、pre-commit 和 CI 共同执行。
