| [AGENTS.en.md](AGENTS.en.md) | 主协定英文版（二选一使用，勿同时注入） |

## 与运行时权威版本的关系

本仓库 Agent 运行时**不读取本目录**；权威版本在 `entities/groups/exmachina/`：

- `protocol/`：13 份按触发词注入的协议（frontmatter 元数据 + SyncReport 回流契约），是本目录参考版的演化上游；
- `prompts/`：40 个角色提示（对应参考版协议第五章的连结体/子个体体系）;
- `SOUL.md` / `entities/skills/`：身份层与技能层。

本目录仅供**外部平台挂载**与离线参考——两套内容同源，运行时版本优先。

## 外部平台接入

最小接入（所有平台通用）：把 `AGENTS.md`（或英文版）全文挂载为常驻指令。

标准接入：主协定常驻；任务涉及调试/审查/发布/回滚时，让模型按需读取相关协议章节（第五、六章的路由与执行循环已内含索引）。

多智能体平台：以 `AGENTS.md` 第五章的角色定义创建子代理；单会话平台无需接入，主协定内的路由逻辑会让单一会话按需串行模拟所需角色。

## 接入后的预期差异

对同一个修复任务：

- **未接入**：模型直接猜测原因并给出改动。
- **接入后**：模型先锁定任务边界 → 列出证据与缺口 → 区分事实/推断/假设 → 给出最小可逆修复与回退路径 → 显式保留残余未知。

简单任务（问候、翻译、总结已给定文本）不应触发这套行为模式。
