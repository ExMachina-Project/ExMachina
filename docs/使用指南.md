# 使用指南

EXMACHINA 的全部交互面：CLI 命令、WebUI 面板与典型工作流。

## 先弄懂三个概念

- **交互目标**：你当前对话的对象，二选一——某个**智能体组**（指挥体带领子个体集体协作）
  或某个**智能体**（如默认的 Machina，直接单独服务）。切换入口在 WebUI「对话」页左栏，切换即切换会话上下文。
- **指挥体 / 子个体**：组模式下，主智能体（指挥体）收拢你的目标 → 分解为任务 DAG → 并行派发给组内子个体 →
  回流校验 → 冲突裁决 → 收束回答。
- **三账**：每场会话的三份账本——任务账（目标/验收/约束）、证据账（A–D 证据分级）、风险账（影响/阻断/回退），
  回答全程可追溯。

## CLI

### 对话与观察

```bash
exm chat                                 # 进入交互对话（Ctrl+C 退出）
exm chat "重构 config 模块并补齐测试"      # 单次下达任务
exm tasks <sessionId>                    # 查看某场会话的任务图（节点状态/依赖/回流）
exm agents                               # 个体编成清单（可 --capability 过滤）
exm serve --port 4173                    # 启动网关（REST + WS + WebUI）
```

### 智能体组

```bash
exm group list                           # 组清单（内置组"智械集群" + 自定义组）
exm group create 研发组                   # 建组（空组；--id/--description 可选）
exm group switch 研发组                   # 切换激活组（后续会话归属该组）
exm group info 研发组                     # 组详情：主智能体/成员/工作区
exm group export 研发组 --out team.json       # 导出为可分享的组包
exm group import --file team.json             # 从组包导入为新组
exm agent create 主脑 --identifier chief --description "组内主智能体" --tier orchestrator
                                         # 组内建个体；首个个体自动成为主智能体
exm agent remove chief                   # 删除组内个体（内置组受保护不可改）
exm group delete 研发组                   # 删除组（激活组不可删）
```

组内主智能体拥有 `agent_manage` 工具：任务执行中可按用户要求创建/修改组内子个体。

### 经验优化

```bash
exm agent optimize context-agent         # 触发教训提炼：把该个体的受阻教训合成行为改进要点
exm agent adaptation context-agent       # 查看当前生效的行为改进要点
exm agent reset-adaptation context-agent # 重置（恢复为无附加要点）
```

### 智能体与人设

```bash
exm persona get machina                  # 查看人设（标注 默认/自定义）
exm persona set machina --text "以武侠风格说话，简洁而有侠气。"
exm persona reset machina                # 恢复默认智械体风格
```

人设只影响说话风格，不影响职责；保存后下一次对话即生效。

### 记忆

```bash
exm memory add --kind fact "构建入口" "cargo build --release" --pin             # 群体共享
exm memory add --kind fact "常用探针" "curl /api/health" --agent machina        # 某智能体私有
exm memory search "构建 入口"                                                   # 检索（显示得分与理由）
exm memory stats                                                                # 群体/个体统计 + 可靠性
exm memory pin <id> && exm memory decay && exm memory reindex                   # 固定 / 衰减 / 重建索引
```

派发时自动注入「该个体私有 + 群体共享」记忆；每次任务自动写入摘要、决策、A/B 级证据与受阻教训。

### 模型（提供商档案）

```bash
exm model list / add / use / remove / test    # 多厂商档案：详见 docs/安装指南.md
```

### 文件检查点（回滚）

写 / 编辑文件**落笔前自动快照**到 `.exmachina/checkpoints/<日期>/<相对路径>`（同日同名只留一份，
即「当日首次改动前」的版本）：

```bash
exm checkpoint list                 # 看快照清单（日期 / 文件 / 大小）
exm checkpoint restore src/main.rs  # 回滚到最近一份（可加 --date 2026-09-18 指定日期）
```

### 平台能力

```bash
exm skill add --id release-check --trigger "发版" --instructions "发布前必须跑通 cargo test 与 e2e"
                                         # 技能包：任务命中触发词时自动随派发注入
exm cron add --name 每日巡检 --cron "0 9 * * *" --prompt "检查未决任务与受阻节点" --group 智械集群
exm cron enable/disable/run/remove ...   # 定时任务（网关常驻时自动调度）
exm approval list / approve / deny       # 终端命令审批闸门（off/risky/always 三档）
```

## WebUI

侧栏 14 个面板，按编号顺序排列；界面为深色控制台风格（工程图网格、面板角标、等宽读数），
支持中英双语导航与 5 套强调色主题（荧光青 / 矩阵绿 / 琥珀 / 紫芒 / 冰蓝）。

| 面板 | 用途 |
|------|------|
| 对话 [CHAT] | 主交互面：**切换交互目标（组 / 智能体）**、会话管理、实时流式输出、任务时间线 |
| 智能体 [AGENTS] | 智能体管理：新建 / 删除 / **默认模型设置** |
| 智能体组 [GROUPS] | 组编成：成员增删、主智能体设立、组工作区、**组默认模型** |
| 子个体 [UNITS] | 激活组编成清单、人设编辑、经验优化（教训提炼为行为要点） |
| 技能 [SKILLS] | 技能包：触发词命中即自动注入被派发个体的上下文 |
| 模型设置 [MODELS] | 模型接入唯一下发处：提供商档案（四协议、Key 池、连通测试、全局默认）+ 每家提供商的模型清单（视觉 / 语音能力开关）+ 能力模型（语音合成 / 语音识别 / 视觉转述 / 嵌入） |
| 任务图 [DAG] | 任务依赖图可视化（按拓扑深度分层，节点状态实时变色） |
| 自动化 [CRON] | 定时任务（cron / 一次性）的创建、启停与运行记录 |
| 审批 [APPROVALS] | 终端命令的拦截与放行记录 |
| 通道 [CHANNELS] | QQ 官方机器人 / NapCat / Telegram / Discord / Slack / Matrix / Webhook 接入账号 |
| 三账 [LEDGER] | 任务账 · 证据账 · 风险账 |
| 记忆 [MEMORY] | 记忆检索与治理（文件模式 / 深层模式） |
| 事件 [EVENTS] | 事件溯源回放与实时调度流 |
| 设置 [CONFIG] | 运行时 / 记忆 / 安全 / 自动化（schema 驱动） |

## 典型工作流

**1. 组建自己的团队**

「对话」页左栏 → 无合适组就到「智能体组」新建 → 创建第一个个体（自动成为主智能体）→
继续扩编子个体 → 回到「对话」页切换到该组 → 下达目标，看它分解、派发、收束。

**2. 私人助理（单体）**

「智能体」页新建智能体并设好默认模型 → 「对话」页左栏切到它 → 直接对话，不经指挥体调度。

**3. 异构模型混用**

「模型设置」页录入多家（如 Claude + DeepSeek + 本地 Ollama）→
写作智能体设 Claude、编码组设 DeepSeek、杂务单体用本地模型——**个体 → 组 → 全局**逐级回退。
每组还可在「智能体组 → 组设置」里单独覆盖能力模型（语音合成 / 语音识别 / 视觉转述 / 嵌入）：
不同组用不同模型栈时，各槽位按 **组覆盖 → 全局默认** 解析。

**4. 多模态与能力模型**

每家提供商的「模型清单」里为每个模型勾选能力：勾「视觉」的模型可直接接收图片，
勾「语音」的模型可直接接收音频。生效模型未勾「视觉」时，页面配置的**视觉转述**模型会把图片
转成文字描述再进对话；**语音识别**模型负责把语音消息转成文字；**语音合成**用于播报输出；
**嵌入**驱动记忆语义检索（与「记忆」页设置同源）。

**5. 接入消息平台**

「通道」页按平台接入，均可绑定组、同平台多账号多开：

- **QQ 官方机器人**：q.qq.com 创建机器人 → 填 AppID / AppSecret（WebSocket 长连接，无需公网 IP）→
  群里 @ 机器人或单聊，即以绑定组上下文执行并回帖；审核期间可开「沙箱环境」联调。
- **NapCat / OneBot 11**：NapCat「网络配置」开 WS 服务端 → 填地址与访问令牌（Lagrange 等 OneBot 11 实现同理）。
- **Telegram**：填 BotFather Bot Token，长轮询自动收发。
- **Discord**：开发者门户建应用 → Bot 页复制 token（须勾选 MESSAGE_CONTENT 特权 intent，
  否则服务器频道收到的正文为空，私聊与 @ 提及不受限）；机器人拉进服务器即可对话。
- **Slack**：应用开启 Socket Mode 并授予 `connections:write` → 填机器人令牌（xoxb-）与应用级令牌（xapp-），
  免公网回调地址。
- **Matrix**：填 homeserver 地址（如 https://matrix.org）与访问令牌（Element「帮助与关于」里可查），
  机器人已加入的房间内收发消息。
- **Webhook / QQ 桥 / 微信桥**：社区桥接器把消息 POST 到 inbound，回复经 replyWebhook 或 WS 返回。

以上原生适配器均支持**会话白名单**（防陌生人滥用）与**运行状态**查看（「通道」页状态列：已连接 / 连接异常 + 明细）。

**6. 让 AI 自己干活（自驱）**

- **自主排程**：AI 可用 `schedule` 工具自建定时 / 一次性任务（如「每天 9 点巡检」「明天下午跟进」），
  到期由调度器唤醒本组执行；也可在「自动化」页人工建 cron。
- **后台长任务**：构建 / 测试这类长命令用后台模式启动（拿到 taskId 后轮询输出、可终止），
  不阻塞当前轮次。
- **心跳巡检**：「设置 → 自动化」开启后，网关常驻时按周期唤醒指挥官检查未决任务与受阻节点。
- **少打断**：写前自动快照（检查点）让 AI 可以放心动手，改坏可一键回滚；
  终端命令白名单按「命令 + 子命令」放行，带连接符的组合命令一律拒绝。
- **沙箱防护**：「设置 → 沙箱执行」默认 `workspace` 档 —— 子进程环境净化（密钥类变量不外泄，
  HOME/TMP 重定向到工作区内）；`strict` 档再把联网安装类命令收进审批，Linux/macOS 检测到
  bubblewrap 时自动做系统级隔离（根只读、工作区可写、按需断网）。
- **浏览器自动化**：AI 可用 `browser` 工具开 headless 浏览器读动态页面、走网页流程、截图存档
  （截图落 `.exmachina/screenshots/`）；探测不到浏览器时该工具不下发。
- **收束钩子**：`hooks` 可挂 preTool（可拦截）/ postTool / onRunEnd 命令，用于通知、留痕、指标采集。

**7. 定时巡检**

「自动化」页建 cron 任务（指定组与提示词）→ 网关常驻时到期自动唤醒该组执行，结果落会话；
AI 自己也能用 `schedule` 工具建同类任务（上一条）。
