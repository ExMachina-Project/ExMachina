# 智能体模型分配

模型目录描述“有哪些模型、适合做什么”；模型分配决定某个智能体实际调用哪个模型。模型设置中的“智能体分配”、独立智能体卡片和组详情编辑的是同一份配置。

## 配置入口

1. 在“模型 → 提供商”中添加模型，填写适用用途、相对成本、上下文窗口和适用场景。用途包括对话、规划、代码、审查、摘要、研究、视觉、语音合成、语音识别、嵌入和生图。
2. 要让模型进入公共自动候选目录，开启该条目的“允许自动分配”。默认关闭；旧安装不会自动增加可消费的模型。
3. 在“模型 → 智能体分配”中选择独立智能体、组默认或具体组成员。也可以在“智能体”卡片中打开模型分配，或进入组详情配置主智能体与成员。
4. 设置默认对话模型，按需展开“按功能用途分配”覆盖具体用途。组默认由成员继承；独立智能体不会继承页面当前选中的其他组。

## 分配方式

| 方式 | 行为 |
|---|---|
| 继承默认配置 | 当前用途未覆盖时，文本用途先取本智能体默认，再取所属组的用途/默认，最后取系统默认；辅助能力不使用普通文本模型作为隐式默认。 |
| 手动指定 | 使用明确的提供商与模型名。指挥体提出其他模型也不能覆盖手动设置。仅配置的提供商回退链可在调用失败后接续。 |
| 由指挥体分配 | 指挥体根据任务、成本、用途及使用说明选择。可限定候选列表；留空时使用目录中已允许自动分配且适合该用途的模型。 |
| 关闭此能力 | 不下发该辅助能力的工具，执行层也拒绝调用。适用于语音、视觉转述、嵌入和生图。 |

原有的 `modelHint`、组 `model`、组能力槽位和系统能力槽位继续兼容。首次打开新编辑器会把原值带入草稿；保存 `modelRouting` 后，新规则成为该对象的配置来源，旧字段不会再次压过“继承”。

## 自动分配与成本

每个模型可标记“经济、均衡、高成本”或“成本未标注”。这是操作者的相对成本说明，不代表自动获得的实时供应商报价。

适用场景说明可写为：“速度快，适合格式整理、例行摘要与简单代码修改；长链路推理和高风险审查使用其他模型。”分配说明可写为：“例行任务优先经济模型；复杂架构设计和安全审查优先更强模型。”

组规划可以为节点提供 `modelSelection`（用途、候选模型和理由）。运行时再次验证候选范围。未提供选择的自动任务会调用当前主智能体的规划模型完成选择；若规划模型本身也自动分配，决策使用系统已配置的默认模型来避免递归。自动选择与请求失败均不会扩展已允许的候选范围。

自动选择会产生额外一次轻量决策调用。组规划已给出合法模型选择时直接使用；手动指定不产生选择调用。分配失败、没有合适候选或返回了未允许的模型时会明确报错。

## 实际调用与失败

运行轨迹及事件页显示 `model.selected`（模型、用途、生效来源、自动分配理由）与 `model.used`（实际成功调用的模型）。明确的 `提供商/模型名` 会保留到请求，不能被提供商默认模型替换。节点模型选择随任务图与派发单保存，任务恢复继续使用这些信息。

普通对话、组规划、节点派发、派生子任务、摘要、研究、视觉转述、语音与生图均使用执行智能体的模型规则。通道入站语音和主动回复决策使用通道绑定目标；切换管理页面的交互目标不会改变正在执行的会话归属。

“在吗、你好、谢谢、晚安”等输入与其他对话一样调用真实模型。没有关键词固定回复；上游额度不足、鉴权失败、网络错误等会生成系统失败信息和失败快照。未被 @ 的群聊消息是否主动回应也由模型结合上下文判断，决策失败保持不回应。

如果派发已经产生真实结果，而最终总结调用失败，系统可以展示已完成节点的结果并明确说明收束失败；没有已完成节点时整轮报错。

## 嵌入模型

嵌入用途支持固定、继承和关闭。不同模型的向量空间不能直接比较，因此每个记忆条目的新向量按提供商与模型名分别保存，相似度只比较同一模型且维度相同的向量。旧的未标记向量保留在原字段；新检索不会把它们冒充为某个已知模型生成的向量，未匹配的记忆仍可通过词项检索命中。

## 管理接口

| 方法与路径 | 用途 |
|---|---|
| `GET /api/llm/catalog` | 脱敏模型目录，不返回密钥。 |
| `GET /api/singles/{id}/model-routing` | 独立智能体的规则和各用途生效来源。 |
| `PUT /api/singles/{id}/model-routing` | 完整替换独立智能体的分配规则。 |
| `PUT /api/groups/{id}/model-routing` | 完整替换组默认分配规则。 |
| `GET /api/groups/{gid}/agents/{identifier}/model-routing` | 指定组成员的规则及生效来源。 |
| `PUT /api/groups/{gid}/agents/{identifier}/model-routing` | 完整替换指定组成员的规则，不切换活跃目标。 |

请求形态示例：

```json
{
  "default": { "mode": "fixed", "model": "primary/small" },
  "purposes": {
    "review": { "mode": "auto", "candidates": ["primary/reviewer", "backup/reviewer"] },
    "speech": { "mode": "disabled" },
    "embedding": { "mode": "fixed", "model": "primary/embedding-model" }
  },
  "instructions": "例行任务优先经济模型，风险较高的审查优先高质量模型。"
}
```
