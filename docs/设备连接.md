# 物理设备连接（实验性）

> 本能力是**实验性、非稳定 API**。默认关闭，不作为生产能力承诺；真实硬件、操作系统权限和厂商协议可能使能力不可用。

## 安全默认值

- `experiments.deviceConnectivity.enabled` 默认 `false`。
- 关闭时不扫描、不配对、不连接、不采集，也不向 Agent 工具面暴露设备动作。
- 系统不执行后台摄像头/麦克风采集；摄像头只支持用户明确请求的一次单帧采集。
- 设备节点与远程 Nexus `LinkTarget` 完全分离。物理设备不会变成远程 Agent，也不会进入远程任务派发路径。

启用实验开关并不等于授权设备。用户仍必须主动发起有界发现、确认配对，并逐项授予能力。

## 支持边界

Core 通过版本化 `DeviceAdapter` 契约接入平台后端。适配器必须声明传输类型和能力；未声明的动作不能执行，也不会提供任意 `device.command`。当前实现提供适配器契约、模拟适配器、无后端蓝牙 `unsupported` 路径和显式 endpoint 的 snapshot 适配器边界；这不代表已接通宿主蓝牙或已在 Gateway/Agent 面启用设备操作。

首批能力边界：

| 传输/协议 | 设备类型 | 能力 | 无后端时 |
|---|---|---|---|
| Bluetooth / system audio | 音响 | `audio_output` | 返回 `unsupported` 或 `unavailable` |
| 用户批准的 Wi-Fi HTTP/JPEG snapshot | 摄像头 | `image_capture` | 返回 `unsupported` 或 `unavailable` |
| 用户批准的 ONVIF snapshot | 摄像头 | `image_capture` | 返回 `unsupported` 或 `unavailable` |

`BluetoothAdapter::host_default()` 在没有注入平台后端时明确返回 `unsupported`；`WifiSnapshotAdapter` 必须由调用方用用户批准的 endpoint allowlist 显式构造，不会在 Core 启动时注册或扫描网络。

发现结果只是待授权候选，不是已配对设备。配对、连接和动作只有在对应适配器真实确认后才报告成功；离线、权限不足和协议不支持必须如实返回。

## 配置与资源限制

配置路径为 `experiments.deviceConnectivity`，由 Core schema 驱动设置界面：

| 字段 | 默认值 | 作用 |
|---|---:|---|
| `enabled` | `false` | 实验总开关 |
| `maxDiscoverySecs` | `30` | 单次发现最长时间，硬上限 300 秒 |
| `maxDiscoveryResults` | `32` | 单次候选数量，硬上限 256 |
| `maxAudioBytes` | `20971520` | 单次播放音频大小上限 |
| `maxAudioDurationSecs` | `300` | 单次播放时长上限 |
| `maxImageBytes` | `10485760` | 单帧图像大小上限 |
| `maxImageEdge` | `4096` | 图像最长边上限 |
| `captureIntervalSecs` | `1` | 同设备单帧采集最小间隔 |

旧配置迁移到当前版本时，设备实验字段补为关闭；既有 `nexus.links` 原样保留，旧远程连结体不会被当作物理设备。

## 生命周期与授权

管理面生命周期为：

1. 用户选择传输类型、范围和有限时长，主动发起 discovery。
2. 用户查看候选后明确确认 pair，并选择能力 grant。
3. 需要时显式 connect；适配器报告真实状态后才可执行能力动作。
4. 用户可 revoke 能力或 unpair 设备；后续动作拒绝，活动动作进入取消/失败状态。
5. 关闭实验开关会清除候选、取消活动动作并断开运行态暴露。

每个请求携带 `requestId`、`actor` 和可选 `sessionId`。设备服务发出安全审计摘要，包含设备标识、动作、结果、错误类别和时间，不包含媒体正文、访问令牌、配对密钥或密码。

## 稳定错误类别

设备 API/事件只依赖以下类别，不把平台原始错误直接暴露给客户端：

`unsupported`、`unavailable`、`forbidden`、`invalid_request`、`not_found`、`conflict`、`limit_exceeded`、`invalid_media`、`cancelled`、`internal`。

特别地：

- 未启用实验开关、未配对或未授予能力：`forbidden`；
- 没有适配器或适配器未声明动作：`unsupported`；
- 设备离线、连接超时或宿主后端暂不可用：`unavailable`；
- 媒体超过大小/时长/频率限制：`limit_exceeded` 或 `invalid_media`；
- 解绑、撤销授权或关闭开关中止动作：`cancelled`。

## 局域网与隐私边界

- 网络设备只能访问用户明确添加并批准的端点；不得借发现请求扫描公网、扩张到其他子网或跟随越界重定向。
- 凭据由服务端安全配置管理，不写入 `DeviceRecord`、普通日志、审计事件或客户端响应。
- 音频动作只接受已登记媒体产物/语音引用；摄像头结果只进入受控的会话媒体链路。
- 普通日志和审计只保存引用/元数据，不保存图像或音频正文；媒体受大小、频率和生命周期限制。
- 一次采集完成或会话结束后不会继续产生帧，除非用户再次明确请求。

没有真实硬件时，使用 Core 的 `SimulatedAdapter` 验证发现、配对、授权、离线、撤销和取消流程；真实蓝牙/摄像头验收属于可选平台测试，不是默认 CI 前提。
