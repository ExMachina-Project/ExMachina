# 对话即编码（移除独立代码工作台）

> 变更：删除 WebUI「代码」独立视图（CodeWorkbenchView），编码体验完全并入对话页。
> 原则：**对话本身即可用于编码**——不需要单独的编码功能页面。

## 移除清单

| 项 | 说明 |
|----|------|
| `webui/src/views/CodeWorkbenchView.tsx` | 独立代码视图（文件树 + 分页浏览 + 会话引用），删除 |
| 侧栏「代码」导航项 | App.tsx VIEW_KEYS / NAV_ITEMS / 路由渲染，删除 |
| `GET/PUT /api/fs/file`、`GET /api/fs/list` | 编码页专用文件浏览/保存端点，前端零引用，删除（lib.rs） |
| `GET /api/workspace/changes` | 编码页变更视图端点，前端零引用，删除（lib.rs + collect_workspace_changes） |
| `git_panel.rs` + `/api/git/*` | 编码页 Git 面板（前端从未接线），删除（含 tests/git_panel.rs） |
| `Core::save_workspace_file` | 编辑器写入口径，唯一调用方（fs_save）已删，删除 |
| `webui/src/api.ts` 死函数 | fsList/fsFile/fsSave/workspaceChanges/gitOverview/gitOp 及类型，删除 |
| i18n `nav.workbench`/`code.*`/`git.*` 词条 | zh/en 两份词典清理 |

## 保留与新增

| 项 | 说明 |
|----|------|
| `GET /api/workbench/tree`（保留） | @ 文件提及的数据源（.gitignore 口径 + 边界校验），e2e 场景2 仍覆盖 |
| `GET /api/workbench/file`（保留） | read 同口径分页；e2e「工作台改代码与回滚」仍走此端点 |
| `@` 文件提及（新增） | 输入框敲 `@` 弹候选层（文件优先/路径短在前，子串过滤，前 12 条）；↑↓ 导航、Enter/Tab 插入、Esc 关闭；选中把 @片段 替换为 `路径 ` |
| 工具卡 diff/回滚（既有） | edit/patch/git 写卡片逐行 diff 着色 + 检查点回滚按钮，不变 |
| 终端输出面板（既有） | terminal 工具卡分区展示（命令/输出折叠/退出码），不变 |

## 实现要点

- **FileMention.tsx**（新组件）：`mentionCandidates()` 纯函数过滤 + 受控弹层（idx 由宿主驱动）；
  `onMouseDown + preventDefault` 不抢 textarea 焦点，onBlur 延迟 150ms 关闭给点击留事件窗口。
- **ChatView 集成**：`detectMention` 检测光标前最近未被空格隔断的 `@` 段（≤48 字符，误触保护）；
  树懒加载（首次触发拉一次，会话期缓存）；键盘优先级 = 提及导航 > 历史召回（空输入时）> 回车发送。
- **样式**：`.mention-pop` 浮层（输入框上方 8px，最大 560px 宽、264px 高滚动），dark 面板色。
