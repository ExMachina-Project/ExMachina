## 二、系统提示词渐进式披露

**分层结构**（orchestrator.md 10,090 → 8,658 字节，规划提示常驻面净减 ~1.4KB）：

- **常驻层**（提示词本体）：角色、语言纪律、四条硬律、路由层级、分派契约、
  计划输出契约、收束结构、助手优先、记忆纪律。
- **目录层**（规划注入，每技能一行 ~40 字符）：`## 可用技能包`（9 行）+ 协议层索引——
  模型看目录即可决策选路。
- **全文层**（按需注入）：任务目标命中触发词时，技能 instructions / 协议全文
  随派发下发到命中个体（既有机制，`haystack = goal + title + objective`）。

**迁移**：orchestrator.md「# 编码工作流」整节（编辑纪律/edit 用法/终端纪律/搜索策略/
调试流程，~1.6KB）→ `skills/code-edit.json`；原位置替换为 8 行「技能与协议（按需加载）」
指针段（说明权威清单来自运行时注入）。

验证：`cargo test -p exm-core --test tool_surface` 3 项过（工具面断言与提示词文本解耦，未受影响）。

## 三、实验性功能开关（experiments，默认全关）

### 配置面

- `ExmConfig.experiments: ExperimentsConfig { dynamicCompaction, groupSharedContext }`
- 持久化进 config.json（ConfigFile 透传）；config_schema() 新增「实验性功能」分组（两 boolean）。
- REST：GET/PUT `/api/config` 的 `experiments` 段；WebUI 设置页 schema 驱动自动渲染
  （SECTIONS 元数据 + zh/en 词条 + nested 组装清单补 `experiments`）。

### 3.1 动态上下文压缩（dynamicCompaction）

- **工具**：`context_compact`（ToolName::ContextCompact；keepRecent 2-100 默认 12、note）。
- **执行体**：`compaction::compact_now()`——不看条数阈值，窗口外有未压历史即增量压缩，
  落库 `update_compaction`；幂等（已压过返回「无需压缩」）。
- **装配**：Core 装配时开关开启才 `tools.set_compactor(provider, model)`；
  apply_config 重建 orchestrator 时按新开关重装配（热更新成立）。
- **下发门控**：`tool_specs_experiments()`——开关关闭时 schema 剔除（模型看不到）；
  runtime 两条路径（派发 execute / 单聊 chat_execute）均已接。
- **执行放行**：豁免 allowlist（编成 JSON 不会包含它；能力面由 schema 门控控制）。
  MCP 对外暴露（mcp_server base 清单）不含该工具。
- **事件**：`context.compacted`（messagesCompacted / keepRecent / summaryChars）。

### 3.2 智能体组共享上下文（groupSharedContext）

- **注入点**：ExecCtx::run_node 的 DispatchOrder.inputs 构造（协议注入之后）。
- **内容**：`shared_context_input(summary, recent)` 纯函数——组主会话的滚动摘要
  （ensure_compacted 同源）+ 最近对话窗口 → `DispatchInput { ref_id: "sharedContext",
  kind: "context" }`；两者皆空不注入。
- 子个体从此能看到组级任务背景，不再只有 objective 孤岛视角。

### 测试

| 测试 | 断言 |
|------|------|
| tools::实验开关_动态压缩关闭时schema剔除context_compact | 关=剔除 / 开=保留 |
| tools::动态压缩_装配后执行并落库 | 未装配明确报错；装配后压 4 条、summary_upto=4、摘要落库；二次调用「无需压缩」 |
| orchestrator::共享上下文_摘要与窗口拼接 | 两段拼接 / 仅窗口 / 全空不注入 |

全量：`cargo test -p exm-core --lib` 134 过；`--test e2e_scenarios` 4 场景过；
`--test tool_surface` 3 过；`cargo check --workspace` 零错误；webui `npm run build` 过。
