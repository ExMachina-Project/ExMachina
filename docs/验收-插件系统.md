# 验收：插件系统（plugin-system）

> 变更：`openspec/changes/plugin-system/`（四层扩展模型：T0 数据/配置 → T1 声明式 → T2 进程 → T3 内置）
> 日期：2026-10-28　分支：dev

## 一、实现清单

### 1. 清单与注册面（exm-core/src/plugin.rs）

- `PluginManifest`（config.rs）：`plugins/<id>/plugin.json` 四类能力声明（tools/channel/watch/resources）+ process 字段 + exmMin 门槛
- `PluginManager`：目录扫描装载（非法清单拒绝/id 与目录一致/空能力拒绝/版本不满足拒绝）、启停覆盖（config.plugins.state 持久化）、builtin/virtual/process/declarative 四形态
- 能力 trait：`ToolProvider`/`ChannelProvider`/`WatchProvider`/`ResourceProvider` + `PluginProvider` 总契约
- 工具命名空间：`<plugin>__<tool>`（双下划线），接入 ToolGateway（append_plugin_tools；custom 执行链全套复用——http/shell、审计、钩子、落盘）；冲突先注册者胜（config CustomTool 优先于插件）
- 收编：CustomTool → 虚拟插件 `custom-tools`；entities/skills → `builtin-resources`（呈现层登记，不可禁用卸载；执行面零变化 = 既有配置零迁移）

### 2. 进程插件桥（exm-core/src/plugin/bridge.rs）

- stdio 行分隔 JSON-RPC：`PluginProcess`（spawn + 帧编解码 + initialize 握手超时 + shutdown 优雅终止 + SIGKILL 兜底）
- 协议面：tools/list（发现）、tools/call（内容块数组/错误/超时不悬挂）、config/set（凭据内存态不落盘）、watcher.tick（通知）
- `PluginSupervisor` 生命周期治理：崩溃指数退避重启（1s/2s/4s…上限 60s）、连续 5 次失败置 Error 停止重试、semaphore 并发排队（默认 4）、`shutdown_all` 宿主关闭全量回收

### 3. video 迁移为首个 builtin 插件

- `crates/exm-gateway/src/plugins/video.rs`：原 video.rs **原样移动**（函数体零改动）
- `plugins/video/plugin.json`：磁盘清单声明 channel（bilibili/youtube + sessdata/biliJct/uid/apiKey 凭据面）+ watch（10 分钟）
- `plugins/mod.rs`：`VideoPlugin` 实现 PluginProvider（ChannelProvider + WatchProvider）；`spawn_all(core)` 取代 lib.rs 直呼 `video::spawn_supervisor`（其余内置通道保留静态序列）
- 注册路径：`register_builtin_late`（运行期补注册，读 config.plugins.state 覆盖快照）

### 4. 管理面与安全（任务组 4）

- REST 端点 `plugin_admin.rs`：GET /api/plugins（列表/状态/形态/能力摘要）、GET /api/plugins/:id（详情/清单/健康）、PUT enabled（持久化 config.plugins.state）、DELETE（builtin/virtual 403 拒绝；目录插件删 plugins/<id>/ 并清理状态）
- 审计归因：tool.call / tool.result 事件带 `plugin` 字段（`<plugin>__<tool>` 名字解析）；非插件工具为 null
- 凭据脱敏：通道脱敏判定改「静态表 ∪ 插件清单 sensitive 凭据键」双源（is_sensitive_config_key）——video 清单声明的 sessdata/biliJct/apiKey 自动掩码
- 文件系统边界：`sandbox_path`（进程插件路径限 plugins/<id>/data/；绝对路径/`..`/Windows 盘符全拒绝）
- WebUI：PluginsView（卡片/启停/卸载/详情抽屉含清单与健康）+ App 导航项 + i18n（zh/en）；ChannelsView 平台目录动态并入插件清单声明的 kinds

### 5. 收尾

- `exm doctor` 插件段：目录装载计数/形态分布/拒绝原因/启停覆盖悬空提示（builtin 随网关注册的口径注明）
- README 功能矩阵加插件行；`docs/插件开发指南.md`（四层形态选型/清单字段/进程协议与 Python 最小实现/治理口径/验收清单）
- 示例插件 `plugins/demo/`（python3 进程形态：hello 工具 + 状态写入 + 凭据内存态 + watcher 应答）——手动冒烟全链路通过

## 三、已知边界（按设计取舍）

- watcher 优雅退出（在飞轮询完成后停止）沿用既有 reconcile 指纹失效路径（abort 摘除）；进程插件侧由 shutdown 协议保证
- 文件系统访问限制（plugins/<id>/data/）在 plugin-security spec 范围，随任务 4 管理面一并收紧
- 沙箱/cgroup 不做 per-插件限制（design.md D7 明示）
