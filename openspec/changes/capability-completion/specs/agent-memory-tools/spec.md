# Spec Delta

## Purpose

智能体自持记忆：把记忆的读/写/关联能力以工具形式交给模型，使其在执行中即时固化与检索知识，而非仅依赖事后归纳。

## ADDED Requirements

### Requirement: 记忆检索工具

系统 SHALL 提供记忆检索工具：智能体调用后按查询返回组内命中条目（含其个体私有层），条目 MUST 携带内容、类型、证据等级、重要性与来源；检索 MUST 遵循组隔离，MUST NOT 返回其他组条目。

#### Scenario: 组内检索

- **WHEN** 智能体以关键词检索记忆
- **THEN** 返回按相关度排序的组内条目列表，私有与群体来源分别标注

#### Scenario: 越组隔离

- **WHEN** 智能体检索的关键词仅存在于其他组的记忆中
- **THEN** 结果不含其他组条目

### Requirement: 记忆写入工具

系统 SHALL 提供记忆写入工具：智能体可写入六类记忆条目，写入 MUST 经内容哈希去重，来源 MUST 标注为智能体自写，并进入与既有写入一致的衰减、检索与个体归属体系。写入 MUST 受工具白名单约束（默认仅主智能体与获授权个体可见该工具）。

#### Scenario: 去重写入

- **WHEN** 智能体写入与既有条目内容哈希相同的记忆
- **THEN** 不产生重复条目，既有条目重要性按既有规则提升

#### Scenario: 白名单约束

- **WHEN** 未获授权的个体尝试调用记忆写入工具
- **THEN** 该工具不在其工具面中，调用不可达

### Requirement: 记忆关联与主题列示

系统 SHALL 支持智能体列示某主题下的记忆并建立条目间关联：列示返回排序条目及其关联链；关联 MUST 写入关联索引并在后续检索中可见。

#### Scenario: 建立关联

- **WHEN** 智能体将两条记忆标注为派生关系
- **THEN** 关联持久化，其后任一条目的列示结果中可见该关联
