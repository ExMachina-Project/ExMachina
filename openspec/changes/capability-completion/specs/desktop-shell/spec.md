# Spec Delta

## Purpose

桌面系统集成：让 Tauri 壳具备常驻、通知与快捷触达能力，桌面端从"网页套壳"升级为原生应用体验。WebUI/PWA 行为不受影响。

## ADDED Requirements

### Requirement: 系统托盘

桌面应用 SHALL 在启动后常驻系统托盘：托盘菜单 MUST 提供"打开控制面板""显示/隐藏窗口""退出"；关闭主窗口时默认驻留托盘（完全退出行为 MUST 可配置）。

#### Scenario: 关窗驻留

- **WHEN** 用户点击主窗口关闭按钮
- **THEN** 窗口隐藏、应用驻留托盘，网关进程持续运行

#### Scenario: 托盘退出

- **WHEN** 用户从托盘菜单选择退出
- **THEN** 网关子进程与窗口一并终止

### Requirement: 原生通知

桌面应用 SHALL 对关键事件发出系统原生通知：审批请求、定时任务推送、任务完成。点击通知 MUST 聚焦主窗口并定位到相关视图；通知 MUST 可按事件类别在设置中关闭。

#### Scenario: 审批通知

- **WHEN** 会话产生待审批请求且桌面端在运行
- **THEN** 系统通知弹出，点击后主窗口聚焦至该审批卡

#### Scenario: 类别开关

- **WHEN** 用户关闭"任务完成"类通知
- **THEN** 后续任务完成不再弹出系统通知，审批类通知不受影响

### Requirement: 全局快捷键

桌面应用 SHALL 支持注册系统级全局快捷键（默认提供唤起/收起主窗口的组合键，可改绑）：按下后主窗口显隐切换；注册冲突时 MUST 提示并提供改绑入口。

#### Scenario: 唤起窗口

- **WHEN** 用户在应用后台运行时按下全局快捷键
- **THEN** 主窗口前置显示；再次按下则隐藏

#### Scenario: 快捷键冲突提示

- **WHEN** 所注册组合键已被其他应用占用
- **THEN** 应用提示注册失败并引导至设置页改绑
