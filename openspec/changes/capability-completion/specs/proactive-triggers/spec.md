# Spec Delta

## Purpose

事件驱动的主动行为：把智能体的唤醒源从"定时 + 入站消息"扩展为"事件源可插拔"，并让定时任务的结果能够主动触达通道订阅者。

## ADDED Requirements

### Requirement: 文件监听触发器

系统 SHALL 支持对工作区内路径模式（glob）注册文件监听触发器：匹配的创建/修改/删除事件经去抖后 MUST 转化为对指定组会话的事件注入（携带事件类型、路径与摘要）。监听 MUST 遵循路径沙箱范围；触发风暴 MUST 由去抖窗口与队列上限兜底。

#### Scenario: 新文件触发处理

- **WHEN** 受监听目录出现匹配模式的新文件
- **THEN** 去抖窗口结束后，目标会话收到包含文件路径与事件类型的事件上下文并触发处理

#### Scenario: 触发风暴被去抖

- **WHEN** 短时间内同一路径产生连续多次变更
- **THEN** 合并为一次事件注入，不逐事件触发

### Requirement: Webhook 事件源

系统 SHALL 提供通用事件 webhook 入口：签名校验通过的事件按映射规则转化为会话注入；校验失败 MUST 拒绝并计入审计。该入口 MUST 与现有通道 webhook 隔离（独立路径与密钥）。

#### Scenario: 签名事件触发

- **WHEN** 携带有效签名的事件到达事件入口
- **THEN** 按映射规则注入目标组会话，事件来源与载荷摘要入审计

#### Scenario: 签名无效拒绝

- **WHEN** 事件签名校验失败
- **THEN** 返回拒绝响应，不注入会话，审计记录来源地址与失败原因

### Requirement: 定时任务结果推送

cron/at 任务 SHALL 支持按任务配置推送订阅：任务完成后将结果摘要推送至订阅通道（复用出站媒体与分段能力）。未配置订阅的任务 MUST 维持现状（仅落会话与运行日志）。推送 MUST 受用量治理约束。

#### Scenario: 订阅通道收到摘要

- **WHEN** 配置了通道订阅的 cron 任务执行完成
- **THEN** 订阅通道收到包含任务名、状态与结论摘要的消息

#### Scenario: 无订阅维持现状

- **WHEN** 未配置订阅的任务执行完成
- **THEN** 结果仅写入关联会话与运行日志，不产生通道消息

### Requirement: 个体粒度心跳

心跳 SHALL 支持配置目标个体/组（per-agent）：以其身份与提示词执行巡检并写入其记忆体系；未配置时 MUST 维持现有全局巡检行为。

#### Scenario: 个体巡检

- **WHEN** 心跳配置指定某单体及其巡检提示词
- **THEN** 巡检以该个体身份执行，产出的教训与摘要进入该个体记忆

#### Scenario: 默认全局巡检

- **WHEN** 未配置任何个体级心跳
- **THEN** 现有全局心跳行为不变
