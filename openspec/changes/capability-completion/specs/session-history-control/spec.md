# Spec Delta

## Purpose

会话历史管控：为对话赋予"可回退、可改写、可分叉"的版本化能力，配合既有文件检查点构成完整的执行 Undo。

## ADDED Requirements

### Requirement: 消息撤销

系统 SHALL 支持将会话回退到指定历史轮次：消息流截断至该轮、上下文按截断后状态重建。回退 MUST 在会话空闲时方可执行（处理中拒绝）；该轮之后由写类工具产生的文件变更 MUST 支持联动回滚（经检查点）；撤销操作 MUST 生成审计事件并保留被截断内容的归档视图。

#### Scenario: 空闲回退成功

- **WHEN** 用户在会话空闲时撤销到第 N 轮
- **THEN** 第 N 轮之后的消息从活跃上下文移除（归档可查），后续上下文基于截断后历史重建，可选联动恢复文件检查点

#### Scenario: 处理中拒绝

- **WHEN** 会话正在处理任务时发起撤销
- **THEN** 撤销被拒绝并提示等待当前处理完成

### Requirement: 编辑重发

系统 SHALL 支持编辑历史用户消息并重发：语义等价于撤销至该消息所在轮次后以新内容重新执行，原内容 MUST 在归档中可查。

#### Scenario: 编辑后重新执行

- **WHEN** 用户编辑第 N 轮的用户消息并确认重发
- **THEN** 会话回退至该轮之前，以编辑后的内容触发新一轮处理

### Requirement: 会话分支派生

系统 SHALL 支持从指定历史轮次派生新会话（分支）：新会话 MUST 携带截至该轮的完整历史副本与派生来源标注，原会话 MUST 保持不变。分支会话的成员、组归属与工具权限 MUST 继承原会话。

#### Scenario: 从历史轮次分叉

- **WHEN** 用户选择第 N 轮创建分支
- **THEN** 生成新会话，包含前 N 轮历史与来源标注，原会话消息与状态不受影响

#### Scenario: 分支独立演进

- **WHEN** 分支会话内继续对话
- **THEN** 新消息仅进入分支会话，原会话与既有归档不变
