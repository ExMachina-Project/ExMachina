# Spec Delta

## Purpose

视觉统一收口：把加载、空态、反馈三类高频状态从「各自为政」拉齐到一致的语言——消除最后的廉价感。

## ADDED Requirements

### Requirement: 列表骨架屏加载

会话列表、个体清单、任务列表等数据列表视图在首次加载时 SHALL 显示骨架屏（与最终布局同构的灰阶占位块）替代居中转圈；数据到达后骨架淡出。

#### Scenario: 会话列表骨架

- **WHEN** 用户进入对话页且会话列表尚未返回
- **THEN** 列表区域显示与条目同构的骨架占位，数据到达后替换

### Requirement: 空状态统一

全部视图的空状态 SHALL 使用统一的图标、主文案与操作引导结构（如「暂无会话 + 新建按钮」）；不再出现无引导的裸 Empty。

#### Scenario: 空状态带引导

- **WHEN** 任一列表无数据
- **THEN** 空状态包含说明文案与下一步操作入口（如新建按钮）

### Requirement: 横幅样式统一

应用内提醒横幅（WS 断连、实验性声明、错误提示等）SHALL 使用统一的横幅样式：一致的圆角、边框、图标位与内边距；同类信息不同视图间呈现一致。

#### Scenario: 横幅样式一致

- **WHEN** 对话页断连横幅与智能连结网络页实验声明横幅同时可见
- **THEN** 两者使用相同的圆角、内边距与图标规格
