# Spec Delta

## Purpose

运行可见性：把「已经有 API 但没有界面」的运行数据（工具审计、限流用量、审批追溯）补上管理入口，让管理员不出后台就能回答「谁在什么时候调用了什么、用量还剩多少、这单审批来自哪」。

## ADDED Requirements

### Requirement: 工具审计页

系统 SHALL 提供工具审计视图：按个体、工具名、时间范围过滤，列表展示每次调用的工具、参数摘要、结果摘要、耗时与时间；数据来源于既有工具审计存储，仅管理可见（受既有鉴权约束）。

#### Scenario: 按个体过滤

- **WHEN** 管理员选择某个体并应用过滤
- **THEN** 列表仅显示该个体的工具调用记录，按时间倒序

#### Scenario: 查看调用明细

- **WHEN** 管理员展开一条审计记录
- **THEN** 可见完整参数（JSON）与结果摘要

### Requirement: 用量统计面板

系统 SHALL 在设置页提供用量统计视图：展示限流开关状态、窗口与配额配置口径、各主体的当前窗口计数；数据来源于既有用量统计接口；限流未启用时 SHALL 显示明确的未启用说明而非空白。

#### Scenario: 查看主体计数

- **WHEN** 限流已启用且有通道请求发生
- **THEN** 面板列出各主体的窗口计数与配额余量

#### Scenario: 限流未启用

- **WHEN** 限流未启用
- **THEN** 面板显示未启用说明与启用入口指引

### Requirement: 审批追溯会话

审批列表中的单条审批 SHALL 显示来源会话入口：点击后打开对应会话并定位到该审批相关的消息上下文；无来源会话的审批（如控制台发起）不显示该入口。

#### Scenario: 从审批跳转会话

- **WHEN** 审批单携带来源会话且管理员点击跳转
- **THEN** 应用切换到该会话视图
