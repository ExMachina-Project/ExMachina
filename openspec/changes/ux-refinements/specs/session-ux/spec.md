# Spec Delta

## Purpose

会话管理易用性：让用户能快速定位、区分与带走会话——搜索、通道会话标识与过滤、Markdown 导出。

## ADDED Requirements

### Requirement: 会话搜索

会话列表 SHALL 支持按标题关键词实时过滤；搜索词匹配标题（不区分大小写），清空搜索词即恢复全量列表。

#### Scenario: 关键词过滤

- **WHEN** 用户在会话列表搜索框输入关键词
- **THEN** 列表仅显示标题包含该关键词的会话，清空后恢复全量

### Requirement: 通道会话标识与过滤

由通道（Telegram/QQ 等）自动创建的会话（`channel:` 前缀标题）SHALL 在列表中携带来源平台标识；列表 SHALL 提供过滤开关（全部 / 仅普通会话 / 仅通道会话），默认全部。

#### Scenario: 平台标识

- **WHEN** 会话由通道自动创建
- **THEN** 列表项显示来源平台标识（如 Telegram），与普通会话可区分

#### Scenario: 类型过滤

- **WHEN** 用户选择「仅普通会话」或「仅通道会话」过滤
- **THEN** 列表仅显示对应类型的会话

### Requirement: 会话导出 Markdown

用户 SHALL 能将任意会话导出为 Markdown 文件：包含全部消息（角色标注）、工具调用摘要行与思维链标记；导出由浏览器下载完成。

#### Scenario: 导出内容完整

- **WHEN** 用户对含工具调用与思维链的会话执行导出
- **THEN** 生成的 Markdown 包含每条消息的角色前缀与正文，工具调用以摘要行形式出现，思维链以折叠引用形式出现

#### Scenario: 空会话导出

- **WHEN** 对无消息的会话执行导出
- **THEN** 生成仅含标题与时间头的空文档，不报错
