- [x] 1.1 `ChatMessage` 增加可选 `thinking`/`tool_calls` 字段（serde default），收束路径由服务端把本轮思维链与工具轨迹写入最终消息——验证：含工具与思考的轮次后，`GET /api/sessions/:id/messages` 返回的过程数据与客户端组装一致

- [x] 1.5 通道 `/stop` 指令：入站闸门最前拦截，映射到该通道会话的停止端点并回执——验证：通道会话运行中发 `/stop` 轮次终止并回执；空闲回执「无运行中任务」
