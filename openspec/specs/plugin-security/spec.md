# plugin-security Specification

## Purpose
插件安全与审计：插件工具调用的审计归因、凭据声明与脱敏、文件系统边界——保证第三方能力接入不破坏既有安全口径。

## Requirements

### Requirement: 工具调用审计归因

插件工具（内置形态与进程形态）的每次调用落入既有工具审计账本，来源标注 `plugin:<插件id>`；watcher 触发的调用额外带 auto 来源标记。审计条目含工具名、参数摘要、耗时与结果状态。

#### Scenario: 审计可区分来源
- **WHEN** 模型经插件工具完成一次调用
- **THEN** 审计账本出现该条目且来源为 plugin:<id>，与内置工具条目在同一账本可检索

### Requirement: 凭据声明与脱敏

通道能力的插件 MUST 在清单中声明凭据字段清单（字段名、是否敏感）。敏感字段 MUST 在管理端点、日志、诊断输出中一律脱敏（掩码显示），仅在下发给插件进程时明文。

插件级凭据区（`plugins.credentials.<插件id>`）MUST 同口径：管理端点回显掩码、日志与诊断脱敏；明文 SHALL 仅出现在两处——T1 声明式工具执行时的变量解析与 T2 进程握手后经 config/set 的下发；进程侧凭据不落盘（内存态）。未在清单声明 sensitive 的凭据键 MUST 仍按敏感处理（默认敏感口径）。

#### Scenario: 凭据回显脱敏
- **WHEN** 管理端点返回含敏感凭据字段的插件或通道信息
- **THEN** 敏感值显示为掩码，明文不出现在任何 HTTP 响应、日志与诊断

#### Scenario: 插件凭据区掩码
- **WHEN** 插件详情端点返回该插件的凭据区
- **THEN** 凭据值一律掩码（无论清单是否标记 sensitive），配置写入后回读同样掩码

#### Scenario: 进程插件收到本插件凭据
- **WHEN** 插件凭据区已配置且进程插件握手成功
- **THEN** config/set 下发含本插件凭据明文，进程侧仅内存态，宿主日志对值脱敏

#### Scenario: 敏感字段声明
- **WHEN** 清单 channel.credentials 声明字段且标记 sensitive
- **THEN** 该字段在通道配置表单按密钥输入渲染，值掩码回显

### Requirement: 进程文件系统边界

进程插件的文件读写仅限其插件数据目录（`plugins/<id>/data/`）；路径穿越（`..` 或绝对路径）被拒绝。协议层不提供任意宿主路径访问能力。

#### Scenario: 越界路径被拒
- **WHEN** 插件经协议请求其数据目录之外的路径
- **THEN** 请求被拒绝并返回明确错误，宿主文件系统不被触碰

### Requirement: 网络与资源限制口径

进程插件的网络访问默认放行（与内置工具同口径）；宿主提供按插件的并发调用上限（默认值可配），超限调用排队而非拒绝。CPU/内存限制沿用宿主进程治理（不在插件协议内单独设限）。

#### Scenario: 并发上限排队
- **WHEN** 并发插件工具调用超过该插件上限
- **THEN** 超出部分排队等待，调用方得到正常时延而非错误

### Requirement: 安装源安全

tar.gz 安装包解包 MUST 防路径穿越（条目名含 `..` 或绝对路径一律拒绝）与超大成员（单文件上限可配，默认 32MB；总解包上限默认 128MB，超限拒绝且无残留）；git 安装 MUST 只取声明的子目录或仓库根的插件文件，`.git` 与仓库其余内容不进入 `plugins/`；安装包内 MUST 仅保留清单主命令文件的可执行位（其余条目可执行位剥离）。

#### Scenario: 路径穿越拒绝
- **WHEN** tar.gz 包内某条目名为 `../../../etc/passwd`
- **THEN** 解包整体拒绝，`plugins/` 无残留，错误信息含该条目名

#### Scenario: 超大包拒绝
- **WHEN** 包内单成员超过单文件上限
- **THEN** 安装拒绝且目录无残留

#### Scenario: 可执行位治理
- **WHEN** 包内多个文件带可执行位
- **THEN** 仅清单主命令文件保留可执行位，其余剥离
